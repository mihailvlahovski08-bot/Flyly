# Flyly

Чет-стил пребарувач на летови од Скопје (SKP).

Ова е статичен сајт: само `index.html`. Летовите се примерни податоци додека не се поврзе вистински flight API.

## Објавување на Vercel

1. Стави ги овие фајлови во GitHub repo.
2. На vercel.com: Add New → Project → избери го repo-то → Deploy. Не треба никакво подесување.
3. За свој домен: Project → Settings → Domains.
